# Security Policy

## Supported versions

Security fixes are made on the current release line and the `main` branch. Older
releases may not receive backported fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
quentin.wach+beamz@gmail.com with a description, affected versions, reproduction
steps, and any proposed mitigation. We will acknowledge the report, assess its
impact, and coordinate disclosure and a fix with you.
